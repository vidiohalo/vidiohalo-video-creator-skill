# Security

## Protect your Agent Key

`VIDIOHALO_AGENT_KEY` authorizes billable actions against a Vidiohalo account.
Keep it in an environment variable or a secrets manager. Do not commit it,
paste it into chat, put it in command arguments, or include it in screenshots.

If a key may have been exposed, revoke it immediately in **Vidiohalo → 个人中心
→ Agent** and create a replacement.

## Reporting a vulnerability

Please do not publish credentials, personal data, or exploitable details in a
public issue. Report security-sensitive problems through the private contact
channel listed on [vidiohalo.com](https://vidiohalo.com).
